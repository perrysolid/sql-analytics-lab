# Data Contract

This document describes the curated `books` table created by the Airflow pipeline.

## Table: books

| Column | Type | Description |
| --- | --- | --- |
| `id` | `SERIAL` | Surrogate primary key generated by PostgreSQL. |
| `title` | `TEXT` | Book title extracted from Amazon search results. |
| `authors` | `TEXT` | Author or contributor text from the result card. |
| `price` | `TEXT` | Raw price text preserved from the source. |
| `rating` | `TEXT` | Raw rating text preserved from the source. |
| `price_amount` | `NUMERIC(10, 2)` | Parsed numeric price for SQL analysis. |
| `rating_value` | `NUMERIC(3, 2)` | Parsed numeric rating for SQL analysis. |
| `source_url` | `TEXT` | Amazon search result URL used during extraction. |
| `scraped_at` | `TIMESTAMPTZ` | UTC timestamp for the extraction run. |
| `inserted_at` | `TIMESTAMPTZ` | Database insert timestamp. |
| `updated_at` | `TIMESTAMPTZ` | Database update timestamp. |

## Quality Rules

- `title` must be present.
- `title` must be unique after the load.
- The target table must not be empty after a successful DAG run.
- Raw text fields are retained for troubleshooting.
- Parsed numeric fields should be used for reporting and ranking.

## Idempotency Rule

The pipeline treats `title` as the natural key for this demo project. Repeated DAG runs use an upsert, so a book that appears again is updated instead of duplicated.
